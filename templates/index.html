Which header should the merged table use?

The tables you're merging have different header rows. Pick which one to keep as the header of the merged table - the others become data rows or are dropped.

Paste HTML (from Froala or elsewhere)

Paste HTML below. It will be converted into editable blocks (headings, paragraphs, captions, lists, tables). Then choose where it should go.

Append to base adds the content to your current base doc. Load as Other puts it in the right-hand pane so you can pull pieces from it. Load as Base starts a new base doc from the HTML. (Froala inline styles like fonts/colours aren't carried over - structure, bold, italic, underline and tables are.)
